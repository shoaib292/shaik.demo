
# 📝 To-Do List Web App

A simple, modern, and responsive To-Do List web application built using HTML, CSS, and JavaScript.

This project helps users organize their daily tasks, track their progress, and manage their work easily.

## 🌐 Live Demo

[Click here to use the To-Do List App](https://shoaib292.github.io/shaik.demo/)

## ✨ Features

- ➕ Add multiple tasks
- ✅ Mark tasks as completed
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 📊 Track total, completed, and pending tasks
- 🌙 Dark Mode and Light Mode
- 💾 Automatically save tasks using Local Storage
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactions
- Local Storage – Saving tasks in the browser

## 🚀 How to Use

1. Open the live demo link.
2. Enter your task in the input box.
3. Click the Add button.
4. Mark tasks as completed when finished.
5. Edit or delete tasks whenever needed.
6. Enable Dark Mode if you prefer a dark interface.
